USER GUIDE

Graph Lab · Grade 7+

Plot, explore, and share math work

Graph Lab combines function plotting, geometry tools, a calculator, and teacher practice mode. Settings are saved in this browser, but graph work is not saved automatically: export a worksheet JSON file to keep or share it.

Functions

  • Choose + Add f(x) or a preset to add a line, quadratic, sine, square-root, or reciprocal curve.
  • Edit the function name and expression. Use the color picker, visibility checkbox, and optional minimum/maximum x-values to customize its plot. Changes can be undone after you finish editing a field.
  • Use Duplicate to make an independent copy. Choose Table to generate values from a start and step, or plot the first seven defined sample points.
  • Enable Shade Integral and set its bounds, or use the canvas Shade Area tool. The displayed signed area is a numerical estimate.
Expression examples: x^2 - 4 · sin(x) · sqrt(x) · 1/x · ln(abs(x)) Supported functions include sin, cos, tan, asin, acos, atan, sqrt, abs, ln/log, exp, floor, ceil, and round. Use pi, tau, and e for constants. Trigonometric functions use the angle unit selected in Settings.

Calculator

Enter an expression directly or use the keypad. Press Enter or choose = to evaluate; click a recent calculation to reuse its result. The recent-calculation list is temporary and is cleared when the page reloads.

  • Use + - * / ^, parentheses, scientific notation (such as 2.5e-3), factorial (5!), and postfix percentage (25%). Adjacent values imply multiplication, so 2pi means 2 × pi.
  • Scientific functions include trigonometric and inverse/hyperbolic functions, square/cube roots, powers, logarithms, rounding, mod(a,b), and combinations/permutations (ncr(n,r), npr(n,r)). Use pi, tau, e, and phi as constants.
  • Ans inserts the previous result (also available as ans in expressions). MC, MR, M+, and M− clear, recall, add to, and subtract from calculator memory; use m to reference memory in an expression. Memory and Ans reset when the page reloads.
  • Quick Solvers include linear equations (ax + b = c), 2×2 linear systems, percentages, the Pythagorean theorem, and quadratic equations (with real or complex roots).
  • Trigonometric functions use the angle unit selected in Settings. Invalid or out-of-range expressions display an error instead of replacing your input.

Settings

  • Choose dark theme, standard or π axis labels, radians or degrees, and a grid-snap step (or turn snapping off).
  • Toggle minor grid lines and axis number labels independently. Zoom with the mouse wheel or canvas buttons; 1:1 resets the view.
  • Teacher / Quiz Mode can hide points, segments, angles, triangles, circles, polygons, integrals, and/or function equations. With interactive checking on, students can submit guesses to reveal verified values. With it off, hidden values remain concealed.
  • Settings are stored locally in the current browser. Reset Settings restores the defaults.

Geometry and canvas tools

  • Inspect: drag to pan, or drag a point to move it. Hover over a plotted curve to inspect its value.
  • Point: click once to place a point. Segment: click its two endpoints. Angle: click the first arm, vertex, then second arm.
  • Right Δ: click two opposite corners to create an axis-aligned right triangle. Circle: click the center, then a point on the circumference.
  • Polygon: click each vertex and double-click to finish. Transform: click a point to create its reflection across the y-axis.
  • Highlight: drag across the canvas. Note: click the canvas, enter text, and choose Add Note.
  • Erase: click near the object or plotted curve to remove it. Undo and redo are available in the header.

Worksheet JSON: save and import

  1. Choose the worksheet button to open the JSON editor. The current functions, geometry, pinned graph notes, and quiz settings are included. The separate Scratchpad text and view position are not included.
  2. Choose Download .JSON File to save a worksheet, or use Copy Code to share its JSON text.
  3. To load one, paste JSON and choose Load Worksheet, or choose Import JSON File and select a .json file.
  4. The app checks the worksheet structure before loading and asks for confirmation because importing replaces the current graph. Invalid files leave your current work unchanged, and you can undo a successful import.

Quiz Mode conceals answers in the interface for practice; it is not a secure assessment system. Worksheet JSON contains the underlying function expressions and geometry values.

Scratchpad and saving

  • The Scratchpad tab is temporary working space and is cleared when the page reloads. Use pinned canvas notes if you want text included in a worksheet JSON file.
  • Export Canvas Image (PNG) saves a picture of the graph. Use Worksheet JSON separately to save editable graph data.
  • Geometry, function plots, and quiz answers are intended for learning and exploration; integral values are numerical estimates.
Graph Lab is a standalone browser app. Keep downloaded worksheet JSON files somewhere safe if you need to reuse them on another device.
